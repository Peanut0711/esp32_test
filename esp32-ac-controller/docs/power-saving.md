# 배터리 절전 운용

배터리 절전 기능은 기본값이 OFF다. 기능 시험과 IR 학습을 마친 뒤 `AUTO SETTINGS`에서 `SLEEP`을 ON으로 바꾸고 `WAKE`를 1~5분으로 설정한 다음 `SAVE & EXIT`를 선택한다.

## 동작 흐름

일반 부팅이나 GPIO1 BACK 버튼으로 깨어난 경우 OLED와 조작 버튼, IR 수신기를 초기화한다. 마지막 노브 또는 버튼 조작과 시리얼 입력으로부터 30초가 지나면 OLED를 끄고 Deep Sleep에 들어간다. BACK 버튼을 누르면 즉시 다시 깨어난다.

RTC 타이머로 깨어난 경우에는 OLED와 IR 수신기를 초기화하지 않는다. SHT40을 한 번 측정하고 자동제어 조건을 검사한 뒤 바로 Deep Sleep으로 돌아간다. `TEMP` 조건은 Wi-Fi를 시작하지 않는다. `BOTH`와 `TIME`은 Deep Sleep 동안 유지된 RTC 시각을 사용하며, 유효한 시각이 없으면 Wi-Fi/NTP 준비를 최대 15초 기다린 뒤 다시 잠든다.

```text
Deep Sleep
  ├─ WAKE 타이머 → SHT40 1회 측정 → 조건 검사 → IR 송신 또는 재수면
  └─ GPIO1 BACK → OLED 메뉴 → 30초 무조작 → 재수면
```

자동 ON을 보낸 날짜와 `TEMP` 조건의 재무장 상태는 RTC 메모리에 보관한다. 따라서 타이머 기상 때마다 같은 신호를 반복하지 않는다. 자동 설정과 프로필은 Preferences, 학습 IR 데이터는 LittleFS에 저장되므로 Deep Sleep 이후에도 유지된다. 전원이 완전히 끊기거나 펌웨어를 다시 올리면 RTC 상태는 초기화될 수 있다.

## 현재 절전 범위

- ESP32-C3 CPU와 디지털 주변장치는 Deep Sleep으로 전환한다.
- OLED에는 화면 OFF 명령을 보내고 화면 버퍼를 지운다.
- GPIO8 내장 하트비트 LED를 끈다.
- Wi-Fi를 연결 해제하고 무선 모드를 끈다.
- IR 수신기를 중지한다.
- SHT40은 단발 측정 후 자체 유휴 상태로 돌아간다.
- RTC 타이머와 GPIO1 버튼을 동시에 기상 원인으로 사용한다.

OLED, IR 모듈과 개발 보드는 계속 3.3V 전원을 공급받으므로 모듈 자체 대기전류와 전원 LED, 레귤레이터 소비전류는 남는다. 더 긴 배터리 수명이 필요하면 다음 하드웨어 단계에서 OLED와 IR 수신기의 VCC를 저대기전류 로드 스위치로 차단하고, 전원 LED와 보드 레귤레이터의 실제 대기전류를 측정한다.

## 배터리 전원에서 기상하지 않을 때

USB 전원에서는 RTC 타이머와 GPIO1 BACK 기상이 모두 정상인데 배터리에서만 실패하면 펌웨어보다 배터리 전원 경로를 먼저 확인한다. 두 기상 방식이 함께 실패하는 대표 원인은 Deep Sleep의 낮은 부하를 감지한 승압 모듈이 출력을 완전히 끄는 경우와, 기상 순간의 부하 증가로 3.3V 전압이 내려가 Brownout 또는 반복 리셋이 발생하는 경우다.

다음 순서로 원인을 구분한다.

1. 배터리에서 `SLEEP OFF`로 두었을 때 계속 정상 동작하는지 확인한다. 이 상태만 정상이라면 저부하 자동 차단 가능성이 높다.
2. Deep Sleep 진입 전후의 보드 `3V3-GND` 전압을 측정한다. Sleep 후 0V가 되면 외부 전원 모듈이 출력을 차단한 것이다.
3. 3.3V가 유지된다면 BACK 버튼 또는 타이머 기상 순간의 최저 전압을 측정한다. 순간 강하가 의심되면 보드 입력 가까이에 470~1000µF 전해콘덴서와 0.1µF 세라믹 콘덴서를 임시로 추가해 비교한다.
4. RESET 버튼도 반응하지 않으면 외부 전원 차단을, RESET은 동작하지만 두 기상 방식만 실패하면 GPIO1 풀업과 기상 설정을 추가로 점검한다.
5. GPIO1 LOW 레벨 기상 시험 시 GPIO1과 3.3V 사이에 외부 10kΩ 풀업을 연결하고 BACK 버튼이 GPIO1을 GND로 당기도록 구성한다.

```text
GPIO1 ── 10kΩ ── 3.3V
GPIO1 ── BACK 버튼 ── GND
```

최종 전원 회로는 저부하 자동 차단이 없는 상시 동작형 레귤레이터를 사용하고 기상 순간의 전류를 감당해야 한다. Espressif는 ESP32-C3의 3.3V 전원에 500mA 이상의 공급 능력을 권장한다. 1셀 리튬이온 배터리는 완충 시 4.2V이므로 보드의 3.3V 핀에 직접 연결하지 않으며, 보호·충전 회로와 적절한 3.3V 전원 변환 회로를 사용한다. 참고: [Espressif ESP32-C3 전원 설계 지침](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32c3/schematic-checklist.html)

진단 결과에는 배터리와 전원 모듈 모델, 배터리를 연결한 보드 핀, Sleep 중 3.3V, 기상 순간 최저 전압, `SLEEP OFF` 지속 동작 여부를 함께 기록한다.

## 운용 주의사항

- IR 학습 중에는 자동으로 잠들지 않는다.
- `SLEEP`을 켠 뒤 시리얼 작업을 하려면 BACK 버튼으로 깨우고 30초 안에 명령을 시작한다.
- 버튼이 눌린 상태에서는 즉시 다시 깨는 현상을 막기 위해 수면 진입을 보류한다.
- `BOTH`와 `TIME`의 정확한 시각 판단을 위해 일반 부팅이나 버튼 기상 시 Wi-Fi/NTP 동기화를 완료한다.
- 1~5분 주기 검사이므로 온도 조건 반응은 최대 설정한 기상 간격만큼 늦을 수 있다.
