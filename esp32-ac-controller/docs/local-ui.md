# OLED 및 로터리 엔코더 UI 설계

대상 모듈은 1.3인치 128×64 SH1106 I2C OLED와 EC11 로터리 엔코더, CONFIRM/BACK 버튼이 결합된 형태다.

## 배선 계획

| 모듈 핀 | ESP32-C3 GPIO | 용도 |
| --- | --- | --- |
| VCC | 3.3V | 모듈 전원 |
| GND | GND | 공통 접지 |
| SDA | GPIO21 | OLED·SHT40 I2C 데이터 |
| SCL | GPIO20 | OLED·SHT40 I2C 클록 |
| 내장 파란 LED | GPIO8 | 일반 UI 동작 중 500ms 주기 하트비트 |
| TRA | GPIO5 | 엔코더 A상 |
| TRB | GPIO6 | 엔코더 B상 |
| PSH | GPIO7 | 엔코더 누름 |
| CON | GPIO10 | 확정/자동 제어 전환 |
| BAK | GPIO1 (선택) | 이전 메뉴 |

모듈은 3.3V로 구동한다. 5V 구동 시 I2C 풀업과 입력 신호가 ESP32-C3 허용 전압을 넘을 수 있다.

ESP32-C3 SuperMini 내장 파란 LED와 I2C가 충돌하지 않도록 OLED와 SHT40의 공통 SDA/SCL 배선을 각각 GPIO21/GPIO20에 연결한다. GPIO8 LED는 LOW에서 켜지는 active-low 방식으로 제어하며, 일반 UI가 동작하는 동안 500ms마다 상태를 바꾼다. RTC 타이머 전용 기상과 Deep Sleep에서는 LED를 끈다.

## 메인 화면

평상시에는 센서값과 제어 상태를 한 화면에 표시한다.

```text
28.4C   52%RH
AUTO: ON   SET:27C
COOL F1  SWING
IR: ON  14:32
```

표시는 작은 화면의 가독성을 위해 `AUTO`, `SET`, `COOL`, `SWING` 등의 짧은 영문 표기를 사용한다.

## 조작 규칙

- 노브 회전: 메뉴 항목을 이동하거나 편집 중인 시간·온도 값을 변경한다.
- 노브 누름: 메인 메뉴 진입 또는 선택한 항목의 편집 단계 이동에 사용한다.
- CONFIRM 버튼: 기본 화면에서는 자동제어 설정을 바로 열고, 메뉴에서는 PUSH와 동일하게 선택한다.
- BACK 버튼: 편집을 끝내거나 변경을 저장하지 않고 이전 화면으로 이동한다.

## 메뉴 구조

```text
메뉴
├─ 송신 시험
│  ├─ 전원 ON/OFF
│  ├─ 모드 COOL/FAN/HEAT
│  ├─ 설정 온도 16~30°C
│  ├─ 풍량 F1/F2/F3/AUTO
│  ├─ 스윙 ON/OFF
│  ├─ 터보 ON/OFF
│  ├─ 선택 상태 송신
│  ├─ 선택 상태를 자동 ON 프로필로 저장
│  └─ 선택 상태 학습
├─ IR 학습
├─ 시계 및 Wi-Fi 조회
└─ 자동제어 설정
   ├─ 자동제어: ON/OFF
   ├─ 조건: BOTH/TIME/TEMP
   ├─ 모니터링 시작 시각
   ├─ ON 기준 온도
   ├─ Deep Sleep: ON/OFF
   ├─ 기상 간격: 1~5분
   └─ 저장 후 나가기
```

에어컨 목표 온도는 실내 온도 제어 기준과 분리한다. 자동 ON 패킷은 `IR TRANSMIT`에서 선택한 전체 상태를 `SET AUTO PROFILE`로 저장해 결정한다. `BOTH`는 시각과 온도를 모두 확인하고, `TIME`은 시각만, `TEMP`는 온도만 확인한다. 자동 OFF 조건은 아직 적용하지 않는다.

## 사용자 지정 IR 송신

메인 메뉴의 `IR TRANSMIT`에서 노브로 항목을 선택하고 PUSH 또는 CONFIRM을 누르면 편집 상태(`*`)가 된다. 노브를 돌려 값을 바꾸고 다시 누르면 편집을 끝낸다. `SEND`를 선택하면 현재 화면의 모든 설정과 정확히 일치하는 학습 패킷을 송신한다.

에어컨 리모컨은 온도·풍량·스윙 신호를 따로 보내는 방식이 아니라 전체 상태를 하나의 패킷으로 보낸다. 따라서 여러 학습 패킷을 조합하지 않는다. 일치하는 패킷이 없으면 `IR TX: NOT LEARNED`를 표시하고 송신하지 않는다. 이때 같은 화면의 `LEARN CURRENT`를 선택하고 원본 리모컨에서 화면과 동일한 전체 상태를 세 번 수신하면 된다. 학습이 끝난 뒤 `SEND`로 바로 시험할 수 있다.

새 사용자 지정 상태는 `ac_c_27_1_s1_t0`처럼 31자 이내의 짧은 이름으로 저장한다. 이전에 수집한 `cool_27_f1_swing_on` 및 `cool_27_f1_swing_on_turbo_off` 형식도 송신 시 자동으로 찾아 사용한다. 전원 OFF는 설정된 다른 값과 관계없이 `power_off` 패킷을 사용한다.

`LEARN CURRENT`에서 현재 조합과 일치하는 저장 신호가 발견되면 확인 화면이 열린다. PUSH는 저장 신호만 삭제하고, CONFIRM은 기존 신호를 삭제한 직후 같은 이름으로 3회 재학습을 시작한다. BACK은 아무것도 변경하지 않고 돌아간다.

`SET AUTO PROFILE`은 현재 조합과 정확히 일치하는 학습 신호를 자동 ON용으로 저장한다. 학습 신호가 없으면 저장하지 않으며, 저장한 프로필은 재부팅 후에도 유지된다.

## 엔코더 입력 진단

물리적인 첫 틱이 누락되거나 이동량이 일정하지 않으면 시리얼 모니터에서 다음 명령으로 A/B 전이 진단을 시작한다.

```text
encoder debug on
```

노브를 한 방향으로 한 틱씩 천천히 돌리면 각 전이마다 `prev`, `curr`, `edge`, `sum`, `move`가 출력된다. `sum`은 유효 전이 누적값이다. 노브가 안정 위치 `AB=11`로 돌아왔을 때 같은 방향 유효 전이가 2개 이상이면 메뉴를 한 칸 이동하고 `move`를 출력한다. 정상적인 한 틱은 대개 4전이를 만들며, 일부 전이가 접점 튐으로 무효가 되어도 2전이 이상이면 해당 틱을 복구한다. `INVALID`가 반복되거나 방향이 불규칙하면 접점·배선을 추가로 점검한다.

```text
encoder debug status
encoder debug off
```

진단 모드는 재부팅 후 자동으로 꺼지며 IR 학습 데이터나 자동제어 설정에는 영향을 주지 않는다.

엔코더 A/B 입력은 GPIO `CHANGE` 인터럽트로 수집한다. OLED 전체 버퍼를 전송하는 동안에도 전이를 누적하므로 화면 갱신 때문에 물리 틱이 빠지는 현상을 줄인다. OLED와 SHT40이 공유하는 I2C 버스는 400kHz로 동작한다.
