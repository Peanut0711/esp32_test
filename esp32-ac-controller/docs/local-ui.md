# OLED 및 로터리 엔코더 UI 설계

대상 모듈은 1.3인치 128×64 SH1106 I2C OLED와 EC11 로터리 엔코더, CONFIRM/BACK 버튼이 결합된 형태다.

## 배선 계획

| 모듈 핀 | ESP32-C3 GPIO | 용도 |
| --- | --- | --- |
| VCC | 3.3V | 모듈 전원 |
| GND | GND | 공통 접지 |
| SDA | GPIO8 | OLED I2C 데이터 |
| SCL | GPIO9 | OLED I2C 클록 |
| TRA | GPIO5 | 엔코더 A상 |
| TRB | GPIO6 | 엔코더 B상 |
| PSH | GPIO7 | 엔코더 누름 |
| CON | GPIO10 | 확정/자동 제어 전환 |
| BAK | GPIO1 (선택) | 이전 메뉴 |

모듈은 3.3V로 구동한다. 5V 구동 시 I2C 풀업과 입력 신호가 ESP32-C3 허용 전압을 넘을 수 있다.

## 메인 화면

평상시에는 센서값과 제어 상태를 한 화면에 표시한다.

```text
28.4C   52%RH
AUTO: ON   SET:27C
COOL F1  SWING
IR: ON  14:32
```

표시는 작은 화면의 가독성을 위해 `AUTO`, `SET`, `COOL`, `SWING` 등의 짧은 영문 표기를 사용한다.

## 조작 규칙

- 노브 회전: 메인 화면에서는 목표 온도를 변경하고, 메뉴에서는 항목 이동 또는 값 변경을 한다.
- 노브 누름: 메뉴 진입, 항목 선택, 값 저장에 사용한다.
- CONFIRM 버튼: 어느 화면에서든 자동 제어 ON/OFF를 전환한다.
- BACK 버튼: 이전 메뉴로 이동한다. 길게 누르면 메인 화면으로 복귀한다.

## 메뉴 구조

```text
메뉴
├─ 자동 제어
│  ├─ 자동 제어: ON/OFF
│  ├─ 켜기 기준 온도
│  ├─ 끄기 기준 온도
│  └─ 최소 유지 시간
├─ 송신 시험
│  ├─ 자동 ON 패킷 송신
│  └─ 자동 OFF 패킷 송신
└─ 화면·시스템
   ├─ OLED 밝기
   ├─ 현재 센서값
   └─ 마지막 IR 송신 정보
```

에어컨 목표 온도(현재는 학습한 27°C ON 패킷)는 실내 온도 제어 기준과 분리한다. 예를 들어 실내 온도가 켜기 기준 이상이면 27°C ON 패킷을 보내고, 끄기 기준 이하이면 OFF 패킷을 보낸다.
