# IR 신호 학습 사용법

펌웨어는 OLED 메뉴에서 목표 상태를 고르거나 터미널에서 이름표를 지정한 뒤, 수신되는 동일한 IR 신호 3개를 LittleFS에 저장한다. OLED에는 현재 이름표와 수집 진행률이 표시된다.

## OLED 학습 메뉴

메인 화면에서 노브를 누른 뒤 `IR LEARN`을 선택한다. 노브 회전으로 학습 항목을 고르고 PUSH 또는 CONFIRM으로 들어간다.

| 항목 | 선택 가능한 목표 |
| --- | --- |
| `POWER` | ON, OFF |
| `MODE` | COOL, FAN, HEAT |
| `TEMP` | 16~30°C |
| `FAN` | F1, F2, F3, AUTO |
| `SWING` | ON, OFF |
| `TURBO` | ON, OFF |
| `TIME OFF` | OFF, 1H~9H |

목표 화면의 `BASE`는 다른 설정을 고정할 기준 상태다. 기본 기준은 냉방 27°C, 풍량 1단, 스윙 ON, 터보 OFF, 예약 OFF다. 학습할 항목 하나만 목표값으로 바꾸고 나머지는 기준 상태를 유지한다. 이렇게 하면 모든 설정 조합을 수집하지 않고도 패킷에서 각 설정이 바꾸는 부분을 비교할 수 있다.

목표값을 고른 뒤 CONFIRM을 누르면 수신 대기 상태가 된다. 그 다음 원본 리모컨을 수신기로 향하게 하고 목표 상태가 되도록 해당 버튼을 누른다. 같은 상태 신호를 다시 만들 수 없으므로, 두 번째와 세 번째 샘플 전에는 리모컨을 수신기 반대쪽으로 향해 다른 상태로 바꾼다. 다시 수신기를 향한 상태에서 목표 상태로 되돌려 총 3개를 저장한다.

저장이 끝난 화면에서 PUSH를 누르면 같은 항목의 다음 목표값으로 이동하고, CONFIRM은 현재 목표 화면에 머물며, BACK은 항목 선택으로 돌아간다. 학습 중 BACK은 현재 학습을 취소한다. 이미 저장된 이름이면 기존 데이터를 보호하기 위해 시작하지 않으며 OLED에 오류가 표시된다. 터미널에서 `erase <label>`로 기존 항목을 삭제한 뒤 다시 시작할 수 있다.

## 명령

| 명령 | 동작 |
| --- | --- |
| `learn <label>` | 지정한 이름으로 다음 동일 신호 3개를 학습한다. |
| `cancel` | 진행 중인 학습을 취소하고 부분 데이터를 삭제한다. |
| `list` | 저장된 이름과 샘플 개수를 출력한다. |
| `show <label>` | 한 항목의 3개 raw 배열을 C++ 형식으로 출력한다. |
| `export` | 저장된 모든 항목을 C++ 형식으로 출력한다. |
| `erase <label>` | 지정한 학습 항목을 삭제한다. |

이름표는 영문자, 숫자, `_`, `-`만 사용할 수 있고 최대 31자다. 펌웨어 업로드는 학습 데이터를 지우지 않지만, 플래시 전체 지우기나 파일 시스템 포맷은 데이터를 삭제한다.
같은 이름이 이미 저장되어 있으면 기존 데이터를 보호하기 위해 새 학습을 시작하지 않는다. 다시 수집하려면 먼저 `erase <label>`을 실행한다.

## 터미널 수집 절차

예를 들어 냉방 26°C, 풍량 1단, 스윙 ON, 터보 OFF 상태를 수집하려면 다음 명령을 입력한다.

```text
learn cool_26_f1_swing_on
```

OLED에 `SAMPLE 0 / 3`과 `PRESS REMOTE`가 표시되면 목표 상태 신호를 세 번 수신한다. 두 번째부터는 raw 길이, protocol, bits, value가 첫 번째 샘플과 일치해야 저장된다. 다른 신호가 들어오면 해당 신호는 거부되고 샘플 수는 증가하지 않는다.

같은 상태를 반복해서 보내려면 원본 리모컨을 수신기 반대쪽으로 향해 다른 값으로 변경한 뒤, 다시 수신기를 향해 목표 값으로 되돌리는 버튼을 누른다. 예를 들어 26°C 신호는 보이지 않는 방향에서 25°C로 내리고, 수신기를 향해 온도를 올리는 과정을 세 번 반복한다.

학습 도중 OLED의 BACK 버튼 또는 `cancel` 명령으로 취소할 수 있다.

## 우선 수집할 상태

```text
cool_26_f1_swing_on
cool_27_f1_swing_on
cool_28_f1_swing_on
cool_27_f2_swing_on
cool_27_f3_swing_on
cool_27_fauto_swing_on
cool_27_f1_swing_off
mode_fan_27_f1_swing_on
mode_heat_27_f1_swing_on
cool_27_f1_swing_on_turbo_on
cool_27_f1_swing_on_timer_1h
cool_27_f1_swing_on_timer_off
power_on
power_off
```

수집을 마친 뒤 `list`로 모든 항목이 `3/3 samples`인지 확인하고 `export` 결과를 보관한다.
